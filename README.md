# DAILY SUCCESS — iPhone install package

WHAT'S INCLUDED
- Responsive black-and-gold planner
- Daily checklist, calendar/events, work tasks, goals/habits, notes
- Automatic on-device saving using browser storage
- Daily reset of checklist and habit checkboxes
- Offline shell caching after the first visit

IMPORTANT
This folder is a Progressive Web App (PWA). iPhone installation requires the files to be hosted at a secure HTTPS web address. This ZIP alone cannot be installed directly from Files as an iPhone app.

HOSTING / INSTALL
1. Upload the contents of this folder (not the enclosing folder) to an HTTPS static host.
2. Open the HTTPS address in Safari on your iPhone.
3. Tap Share, then Add to Home Screen.
4. Confirm the name "Daily Success" and tap Add.

DATA
Planner data is stored locally in the browser on that device. Clearing Safari website data or removing the app may erase it. This prototype does not sync across devices.

NOTIFICATIONS
The app currently stores calendar entries but does not send scheduled push notifications. Reliable iPhone web push requires an installed PWA plus a push service/backend and user permission; that is a separate setup step.
